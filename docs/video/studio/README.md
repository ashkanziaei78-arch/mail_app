# استودیوی فیلم — «میلینگ پِرِس» (طراحیِ تازه، از صفر)

ویدیوی عمودیِ ۱۰۸۰×۱۹۲۰، ۳۰fps، ۱۲۶ ثانیه، **بدون موسیقی** (موسیقی را خودتان می‌گذارید)
با گویندگیِ فارسیِ اعراب‌گذاری‌شده.

## قراردادِ رندر
هر فریم تابعِ محضِ زمان است: `window.seek(t)` فریمِ لحظهٔ `t` را می‌کشد.
هیچ `transition`، `setTimeout` یا `requestAnimationFrame` در مسیرِ رندر نیست و هیچ حالتی
بینِ فریم‌ها نگه داشته نمی‌شود. تنها منبعِ تصادف `mulberry32` با seed ثابت است، پس
رندر تکرارپذیر است.

## زبانِ بصری
زمینهٔ کاغذِ تحریریه (`#F4F1EA`)، مرکّبِ سرمه‌ای (`#111A22`)، یک رنگِ تأکید (`#A8401F`).
یک قلمِ نمایشی و یک قلمِ رابط (هر دو Vazirmatn، وزن‌های متفاوت).
تیترها هم‌تراز با شبکه و راست‌چین‌اند — هرگز وسطِ قاب. متن با `clip-path` باز می‌شود — هرگز
با fade. نشانگرِ فصل داخلِ شبکه است، نه چیپِ گوشهٔ قاب. گذرِ پرده‌ها لغزشِ ورق است.
نشانِ محصول با **فشارِ مُهر** می‌آید (`scale(3.4→1)` + حلقهٔ بازشونده)، نه با انفجارِ ذرّه.

## اجرا
```bash
node render.mjs sheet     # کانتکت‌شیت: یک فریم سرِ هر ضرب  → contact-sheet.png
node render.mjs           # رندرِ کامل  → میلینگ-پرس.mp4   (CRF 16، yuv420p)
```

## صدا
```bash
FISH_API_KEY=... FISH_VOICE_ID=... node tts-fish.mjs   # vo/L01.wav ... vo/L22.wav
node mux-vo.mjs میلینگ-پرس.mp4 میلینگ-پرس-باصدا.mp4    # چیدنِ صدا سرِ ثانیهٔ دقیقِ خودش
```
متنِ گفتار در `vo/lines.json` است و **از پیش اعراب‌گذاری شده** تا تلفظ درست دربیاید؛
دست نزنید. `mux-vo.mjs` عمداً هیچ موسیقی‌ای اضافه نمی‌کند؛ لایهٔ موسیقی برای شما باز است
(`loudnorm` روی گفتار روی I=-16 تنظیم شده تا زیرِ موسیقیِ شما جا باز کند).

## قانونی که رعایت شده
هیچ قابلیتی که در نرم‌افزار نیست ادعا نشده. به‌طور مشخص این سه **نیامده‌اند**، چون در
کد وجود ندارند: ارسالِ ایمیل، واتساپ، و امضای دیجیتالِ گواهی‌دار (PKI). آنچه هست
— تصویرِ امضا، شمارهٔ نامه، هشِ فایل، امضای محتوا و QR راستی‌آزمایی — به همان نامِ
«قابلِ پیگیری» معرفی شده.
