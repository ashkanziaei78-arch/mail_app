## ساخت از صفر

```bash
# ۰) ابزارها: Node 22+، ffmpeg، Python 3 (numpy، scipy، soundfile)، Chromium/Playwright
# ۱) اسکرین‌شات‌ها: اپ روی :3100 با seed، سپس
node capture.mjs approval <campaignId-در-مرحلهٔ-تأیید>
node capture.mjs sent <campaignId-ارسال‌شده> <letterCode>
# ۲) موسیقی و افکت (قطعی؛ seed=1404)
python3 music.py
# ۳) گویندگی (کلید Fish لازم است)
FISH_API_KEY=… FISH_VOICE_ID=… node tts-fish.mjs
# ۴) میکس نهایی: صدای گوینده سر ثانیهٔ دقیق خودش + loudnorm دومرحله‌ای ← assets/audio/mix.wav
node mix.mjs
# ۵) مونتاژ، بررسی، رندر
./assemble.sh --audio-meta ./audio_meta.json
npx hyperframes check
npx hyperframes snapshot --at 1.2,12,23.6,46.8,58.5,79,93,111.8,126   # کانتکت‌شیت
npx hyperframes render --quality high --output renders/park.mp4
```

بدون کلید Fish، `mix.mjs` فقط موسیقی را می‌گذارد و فیلم کامل رندر می‌شود.
بعد از گرفتن کلید، مراحل ۳ و ۴ و ۵ را دوباره اجرا کنید.

اگر خطی از بودجهٔ زمانی‌اش بیشتر شد، `tts-fish.mjs` هشدار می‌دهد.
در آن صورت متن را کوتاه کنید یا `at` خطوط بعدی را جابه‌جا کنید.

## قوانین رعایت‌شده

- **رندر قطعی:** هر فریم تابع محض زمان است.
  - هیچ `transition`، `setTimeout` یا `requestAnimationFrame` در کار نیست.
  - تنها منبع تصادف `mulberry32(1404)` است.
  - GSAP محلی است (`assets/vendor/`)، پس رندر به شبکه وابسته نیست.
- **فقط قابلیت‌های واقعی:** جدول قابلیت‌ها و منبع هر کدام در `BRIEF.md` آمده است.
  - این‌ها **نیامده‌اند**: ارسال ایمیل، واتساپ، امضای گواهی‌دار (PKI) و Form Builder.
  - بله، تلگرام و ایتا در کد فقط به تأییدکننده خبر می‌دهند و فیلم هم همین را می‌گوید.
- **داده‌ها نمایشی‌اند:** داده‌های اسکرین‌شات‌ها از seed می‌آیند و ادعای مشتری نیستند.
  - سازمان نمونه: «پارک علم و فناوری یزد».
  - نامهٔ نمونه از مسیر واقعی API ساخته، تأیید و ارسال شد.
  - تحویل، بازشدن و پاسخ با وبهوک و صفحهٔ عمومی واقعی شبیه‌سازی شد.
