# Asset inventory — real Mailing Press screens (local demo instance, seed data)

All plates: 3200×1800 (1600×900 @2x) unless noted. Org in the demo = «پارک علم و فناوری یزد».
Demo letter: «دعوت به نشست هم‌اندیشی فناوری» to 20 contacts tagged #اتاق_بازرگانی.

- capture/assets/dashboard.png — داشبورد: setup checklist, KPI tiles (مخاطبان ۲۸ …), recent letters list.
- capture/assets/contacts.png — دفترچهٔ مخاطبین: table of contacts with org/position, tags, buttons «ورود گروهی» (import) / «خروجی اکسل».
- capture/assets/tags.png — برچسب‌ها و گروه‌ها: hashtags with member counts (#اتاق_بازرگانی ۲۰ …).

- capture/assets/campaign-approval.png — campaign page mid-approval: approval chain chips (پیش‌نویس ✓ → رئیس اداره ✓ → معاون ⏱ → مدیرکل → ارسال پیامک) + final recipients list «نامه تولید شد».

- capture/assets/m-letter.png — the same letter on a phone (1242×2688).
- capture/assets/reports.png / reports-full.png — گزارش‌ها: KPIs (ارسال موفق ۲۰، نرخ تحویل، نرخ بازشدن، پاسخ‌ها ۹ …), funnel, 30-day chart, CSV export.
