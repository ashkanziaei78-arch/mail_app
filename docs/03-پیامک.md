# اتصال درگاه پیامک

## تنظیم

مسیر: **تنظیمات پیامک** (نیاز به مجوز `sms.settings`).

| فیلد | توضیح |
|---|---|
| درگاه | `آزمایشی` یا `کاوه‌نگار` |
| شماره فرستنده | خط خدماتی سازمان، مثلاً `10008663` |
| کلید API | فقط هنگام ثبت/تغییر وارد می‌شود؛ هرگز به مرورگر برنمی‌گردد |

کلید API با **AES-256-GCM** و کلیدی که از `APP_SECRET` مشتق می‌شود رمزنگاری و در جدول
`SmsProviderConfig` ذخیره می‌گردد. رمزگشایی فقط در `src/lib/sms-server.ts` و لحظه ارسال انجام می‌شود.

> تغییر `APP_SECRET` کلیدهای ذخیره‌شده را غیرقابل رمزگشایی می‌کند؛ پس از تغییر، کلید درگاه را دوباره وارد کنید.

## حالت آزمایشی

درگاه `console` پیامک واقعی نمی‌فرستد و متن را در لاگ سرور چاپ می‌کند:

```
[SMS:console] → 09121110007
سرکار خانم دکتر فاطمه احمدی گرامی، نامه‌ای از پارک علم و فناوری یزد برای شما صادر شد: https://…/l/ypoUpFgyVY
```

برای آزمایش کل مسیر بدون هزینه، همین درگاه را نگه دارید.

## متغیرهای متن پیامک

`{{عنوان}}`، `{{نام}}`، `{{نام_خانوادگی}}`، `{{نام_کامل}}`، `{{سمت}}`، `{{سازمان}}`، `{{شهر}}`،
`{{موبایل}}`، `{{سازمان_فرستنده}}`، `{{تاریخ}}`، `{{شماره_نامه}}`، `{{لینک}}`، `{{کد_دسترسی}}`.

متغیر ناشناخته دست‌نخورده می‌ماند تا در پیش‌نمایش دیده شود و اشتباه تایپی به مخاطب نرسد.

## شمارش بخش پیامک

متن فارسی یونیکد است: تک‌بخشی تا **۷۰** کاراکتر، پس از آن هر بخش **۶۷** کاراکتر.
شمارنده در مرحله «پیامک و ارسال» تعداد بخش‌ها را زنده نشان می‌دهد و درباره هزینه چندبرابری هشدار می‌دهد.

## نامه محرمانه

کمپین محرمانه برای هر لینک یک کد شش‌رقمی می‌سازد و آن را در **پیامک دوم و جداگانه** می‌فرستد،
تا لو رفتن یک پیامک به‌تنهایی دسترسی ندهد.

## افزودن درگاه جدید

در `src/lib/sms.ts` یک تابع با امضای زیر بنویسید و در `resolveProvider` (فایل `sms-server.ts`) اضافه کنید:

```ts
export function myProvider(apiKey: string): SmsProvider {
  return {
    name: "my-provider",
    async send(to, text, sender) {
      // در موفقیت:  { ok: true, providerMessageId: "…" }
      // در خطا:     { ok: false, error: "پیام فارسی" }
    },
  };
}
```

سپس مقدار جدید را به `SUPPORTED_PROVIDERS` اضافه کنید تا در فرم تنظیمات دیده شود.

## ظرفیت ارسال

ارسال در همان درخواست و به‌صورت ترتیبی انجام می‌شود که برای چند صد مخاطب کافی است.
برای کمپین‌های چندهزارنفره، `sendCampaign` را داخل یک worker صف (BullMQ + Redis) صدا بزنید؛
امضای تابع برای همین کار طراحی شده است.
