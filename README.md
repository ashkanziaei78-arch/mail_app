# سامانه میلینگ سازمانی

سامانه مکاتبات سازمانی و ارتباط با مخاطبین: دفترچه مخاطبین (عمومی/خصوصی)، برچسب و گروه،
سربرگ و قالب نامه، ساخت کمپین، تولید نامه اختصاصی برای هر مخاطب، لینک کوتاه امن و ارسال پیامک شخصی‌سازی‌شده.

رابط کاربری کاملاً فارسی و راست‌چین، با تم روشن/تاریک و قابل نصب روی اندروید، iOS و کروم (PWA).

## اجرای سریع (محیط توسعه)

```bash
cp .env.example .env          # سپس APP_SECRET را با مقدار تصادفی جایگزین کنید
docker compose up -d postgres # یا پایگاه داده PostgreSQL خودتان
npm install
npx prisma db push
npm run db:seed               # داده آزمایشی فارسی
npm run dev                   # http://localhost:3000
```

### حساب‌های آزمایشی (گذرواژه همه: `Mailing@1404`)

| ایمیل | نقش |
|---|---|
| `root@mailing.local` | مدیر کل سامانه |
| `admin@mailing.local` | مدیر سازمان |
| `approver@mailing.local` | ناظر / تأییدکننده |
| `user@mailing.local` | کاربر عادی |

> این حساب‌ها فقط داده آزمایشی‌اند. پیش از استقرار واقعی، همه را حذف یا گذرواژه‌شان را عوض کنید.

## استقرار با Docker

```bash
cp .env.example .env   # APP_SECRET و APP_URL را مقداردهی کنید
docker compose up -d --build
docker compose exec app npx prisma migrate deploy
docker compose exec app npm run db:seed   # اختیاری
```

`APP_URL` باید آدرس عمومی واقعی سامانه باشد، چون همین آدرس داخل پیامک به‌صورت لینک کوتاه می‌رود.

## دستورها

| دستور | کار |
|---|---|
| `npm run dev` | اجرای محیط توسعه |
| `npm run build` | ساخت نسخه تولید |
| `npm test` | بررسی منطق‌های حساس (XSS، متغیرها، شمارش پیامک، رمزنگاری، نشست) |
| `npm run db:push` | همگام‌سازی سریع اسکیما (توسعه) |
| `npm run db:migrate` | ساخت migration |
| `npm run db:seed` | داده آزمایشی |

## نکات مهم پیش از استقرار

1. `APP_SECRET` را با `openssl rand -base64 48` بسازید (حداقل ۳۲ کاراکتر).
   اگر مقدار نمونه بماند، برنامه در حالت تولید عمداً بالا نمی‌آید.
   تغییر آن، نشست‌های فعال و کلیدهای API ذخیره‌شده را بی‌اعتبار می‌کند.
2. سامانه را پشت HTTPS بگذارید؛ کوکی نشست در حالت تولید فقط روی اتصال امن ارسال می‌شود.
3. پوشه `public/uploads` (سربرگ‌ها) را به یک volume دائمی وصل کنید.
4. از پایگاه داده پشتیبان منظم بگیرید: `pg_dump -U mailing mailing > backup.sql`.
